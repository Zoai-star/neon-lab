# Neon Lab

Hello!

Acting as a website designer, could you design an website which is a digital science lab, with three main features.

1. Build digital robots and have a ai assistant with facts

2. Have a dna lab where you can put in features of parents a and b and splice the dna

3. Have a chemical mixer where you can mix two things to create another thing which you can mix with another thing!

Please use HTML css and JavaScript and have quizzes in every part. The website should have a neon science lab feel.

Thanks!!
